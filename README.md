# 🚛 Smart Dumper Cycle Time Prediction System

A Machine Learning-based web application that predicts dumper cycle time using mining operational parameters. The application is built with Streamlit and uses a trained Linear Regression model.



- Predicts dumper cycle time
- Estimates trips per hour
- Calculates productivity (TPH)
- Displays operational efficiency
- Shows prediction history
- Download prediction history as CSV
- Interactive Streamlit dashboard



- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib
